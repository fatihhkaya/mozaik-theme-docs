# Support

Open a request at https://github.com/fatihhkaya/mozaik-theme-docs/issues/new/choose and include:

- your store URL (`your-store.myshopify.com`)
- the Mozaik theme version (Online Store → Themes → … → Edit code → `config/settings_schema.json`)
- the steps to reproduce the issue and a screenshot

We answer within two business days. Support covers theme setup and bugs in the theme code. It does not cover custom code changes or third-party apps.
